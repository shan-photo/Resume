# 作品集網站｜更新說明

## 每個月新增作品（只動一個檔案）

1. 把作品照片（建議 1000×750 左右、.webp 或 .jpg）上傳到 `images/` 資料夾。
2. 打開 `data/works.csv`，新增一列（可以用 Google 試算表、Excel、Numbers 開啟編輯，存回 CSV）。
3. 上傳回 GitHub，約 1 分鐘後網站更新。
4. 打開 `你的網址/?check=1` 看檢查清單：哪些欄位待補、代號有沒有重複、圖片有沒有讀不到。

版面、首頁、詳細頁都會自動長出來，不需要改 HTML。

## works.csv 欄位

| 欄位 | 必填 | 說明 |
|---|---|---|
| 代號 | ✔ | 英文小寫加連字號，例：`hao-jia-huo-001`。會變成作品網址 `#/work/代號`，上線後不要改 |
| 顯示 | | 填 `N` 就不公開（草稿、還沒確認的作品）。空白＝公開 |
| 精選 | | 填 `Y` 會出現在首頁「代表作品」，建議維持 4 件 |
| 進行中 | | 填 `Y` 會出現在跑馬燈與列表的「進行中」標記 |
| 年份 | ✔ | `2026` 或 `2025–26`；排序依結束年份 |
| 標題 | ✔ | |
| 類別 | ✔ | 目前：策展、活動企劃執行、採訪出版、影像紀錄、設計編排、國際交流、社群經營。寫新的類別會自動多一個篩選按鈕 |
| 角色 | | 你在這件作品的角色 |
| 合作單位 | | 主辦／委託／合作單位 |
| 摘要 | | 一兩句介紹，顯示在詳細頁標題下 |
| 內容 | | 詳細內容，空一行就是新段落 |
| 成果 | | 例：`B5｜32 頁｜裸背線裝` |
| 封面圖 | | `images/` 裡的檔名，例：`work-unframed.webp` |
| 圖片 | | 更多圖片，用 `｜` 分隔 |
| 圖片來源 | | 攝影者或提供單位 |
| 影片 | | 影片網址。YouTube 會在作品頁直接播放（先顯示封面，按下才載入）；Facebook 等其他網站會顯示封面並連到原影片。有影片的作品在列表會標「▶ 影片」 |
| 外部連結、連結文字 | | 展覽網站、文章等 |
| 備註 | | 只給自己看，網站不顯示（檢查模式會列出） |

只填了標題、角色、年份的作品，在列表上是一行純文字、不能點開（避免點進去只看到兩行字）；只要填了摘要、內容、成果、圖片、影片或外部連結其中一項，就會變成可以點開的作品頁（列表右邊會出現 ▸）。

沒填的欄位，公開網站會直接省略不顯示（不會出現「待補」，也不會自動編內容）。想知道還有哪些沒填，打開 `你的網址/?check=1`：檢查清單和作品頁都會用黃色「待補」標出來，只有加了 `?check=1` 才看得到。

## 現在在做

首頁自我介紹下方的「現在在做」，會自動列出 `works.csv` 裡「進行中」填 `Y` 的作品；案子結束時把它改回 `N` 就會消失。都沒有進行中的作品時，這一區不會出現。

想加一句接案狀態（例如「2026 年 12 月起可接新案」），打開 `index.html`，在上方設定區把文字填進 `availability: ''` 的引號裡；留空就不顯示。

## PDF 履歷

網站首頁和聯絡區都有「⬇ PDF 履歷」按鈕，下載的是 `cv/wu-pei-shan-cv.pdf`（A4、2 頁）。內容由 `works.csv` 和 `experience.csv` 產生，跟網站一致。

注意：PDF 是固定檔案，不會跟著 `works.csv` 自動更新。新增作品後，請 Claude 幫你重新產生一份 PDF，再上傳取代 `cv/` 裡的同名檔案。

## 內容來源：獨立資料檔 vs Google 試算表

| | 獨立資料檔（data/works.csv，目前採用） | Google 試算表當內容來源 |
|---|---|---|
| 更新方式 | 編輯 CSV（可用試算表軟體開）→ 上傳 GitHub | 直接在試算表打字，手機 App 也能改 |
| 圖片 | 跟 CSV 一起上傳到 GitHub，一次完成 | 試算表放不了圖片，**還是要另外上傳到 GitHub** |
| 生效時間 | 上傳後約 1 分鐘 | 發布後通常幾分鐘內，Google 有快取 |
| 網站穩定度 | 資料跟網站在一起，不依賴其他服務 | 每次有人開網頁都要向 Google 讀資料；Google 讀不到時會改用備份 CSV |
| 版本紀錄 | GitHub 保留每次修改，可還原 | 試算表有版本紀錄 |
| 容易出錯的地方 | CSV 裡有逗號的文字要加引號（用試算表軟體存檔會自動處理） | 改了欄位名稱網站就讀不到；試算表必須設為公開發布，不能放私人筆記 |
| 費用 | 免費（GitHub Pages） | 免費 |
| 需要框架／後端 | 不需要 | 不需要 |

**建議：先用獨立資料檔。** 決定性的原因是圖片：你每月新增作品一定要上傳照片到 GitHub，
用 CSV 的話照片和文字在同一次上傳完成；改用 Google 試算表反而多一個要維護的地方，
網站也多一個外部依賴。

如果之後真的很想在手機上直接改文字，網站已經預留切換：
1. 把 `works.csv` 匯入 Google 試算表（欄位名稱保持一樣）。
2. 「檔案 → 共用 → 發布到網路」，選該工作表、格式選「逗號分隔值 (.csv)」，複製網址。
3. 貼到 `index.html` 上方設定區的 `sheetCsvUrl: ''` 引號裡。
4. 打開 `?check=1`，確認「資料來源：Google 試算表」。讀不到時網站會自動改用 `data/works.csv`。

## 重力與煙火

不是獨立的區塊，而是整頁的回饋：

- 點開作品（代表作品卡片、列表、上一件／下一件）時，從點的位置噴出煙火、星星和會彈跳的原子。
- 作品視窗打開時，會順著重力方向「掉」進來；按「聯絡合作」時，聯絡視窗會震一下。
- 手機：傾斜手機改變重力方向，煙火往低處掉，所有視窗的影子也跟著移動；平放手機＝無重力。
  多數 Android 自動開啟；iPhone 要按工作列右邊的「⚛ 重力」按鈕並允許。工作列按鈕也可以關掉感應。
- 電腦沒有感應器，重力固定向下，影子在視窗正下方。
- 系統設定「減少動態」的訪客看不到煙火和掉落動畫。
- 煙火畫在一層不接收點擊的透明圖層上，不會擋住任何按鈕；煙火結束後就停止運算。

## 檔案結構

```
index.html          頁面骨架與聯絡資訊（聯絡寫死在這裡，資料壞掉也找得到你）
assets/style.css    樣式
assets/app.js       讀 CSV、畫列表與詳細頁
assets/fx.js        重力與煙火效果
data/works.csv      ← 每月更新這個
cv/                 PDF 履歷
data/experience.csv 經歷、學歷
images/             作品照片
```

注意：直接雙擊 `index.html` 用檔案開啟時，瀏覽器會擋住讀取 CSV，作品不會出現。上傳到 GitHub Pages 後就正常。
